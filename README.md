# Buzzin - Business Chat Platform

Buzzin is a WhatsApp-inspired chat platform specifically designed for businesses, featuring AI-powered analytics and insights. The platform enables seamless communication while providing valuable business intelligence through conversation analysis.

[Watch Demo Video](https://youtu.be/2MCFaTE14rw)

## Features

- **One-on-One Messaging**: Secure direct messaging between users
- **AI Chat Assistant**: Get insights about your messaging patterns and analytics
- **Business Analytics**: Analyze communication patterns and engagement
- **Simple Authentication**: Phone number based authentication

## Getting Started

### Prerequisites
- Elixir 1.14 or later
- Phoenix Framework 1.7 or later
- PostgreSQL

### Installation

To start your Phoenix server:

  * Run `mix setup` to install and setup dependencies
  * Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.

Ready to run in production? Please [check our deployment guides](https://hexdocs.pm/phoenix/deployment.html).

### Tech Stack
- **Backend**: Elixir/Phoenix
- **Database**: PostgreSQL
- **AI Model**: TinyLlama
- **Frontend**: Phoenix LiveView with TailwindCSS
